# Changelog: Release v1.2.0 — Live Synced Lyrics, Now Brief Weather & Customization

- **Timestamp**: 2026-11-20 21:36:00
- **Author**: AI Engineering Agent / Developer
- **Category**: Feature
- **Target Platform**: Android (minSdk 33, targetSdk 37)

---

## 1. Executive Summary
Release v1.2.0 introduces real-time synchronized LRC lyrics streaming in the Media Player with interactive scrolling, auto-sync recovery, and persistent playback view modes. It integrates real-time keyless weather reporting in the Now Brief powered by Open-Meteo with persistent location coordinate caching, customizable media aura animation color modes (Album Artwork vs. Primary Theme), and an optimized 1m/3s idle notification summary cadence.

---

## 2. Motivation & Problem Statement
- **Media Experience**: Users requested live synchronized lyrics while music is playing, with automatic scrolling and manual interactive exploration that does not accidentally dismiss the expanded capsule while captions are active.
- **Ambient Context**: Weather information in the Now Brief was requested to provide current ambient temperature and atmospheric condition alongside persistent battery metrics, without incurring third-party API costs or battery drain.
- **Visual Refinement**: Notification dismissals required synchronous background blur tracking to eliminate visual lag during fast swipe gestures, and the notification list order was inverted to present newer items at the natural bottom tap target.

- `presentation/src/main/kotlin/com/raf/capsuleos/presentation/setup/`: Removed microphone permission UI row; updated 14 locale string definitions.

## 4. Architectural & KMP Impact
- **Zero Framework Bleed in Domain**: `LrcLyricsParser`, `CapsuleContent.Media`, and `IslandStateCoordinator` remain 100% pure Kotlin with zero Android platform dependencies.
- **Privacy & Security**: Zero microphone usage; location access is strictly optional coarse-only for weather calculations and cached privately.
- **100% Free & Open-Source**: All remote network queries rely solely on keyless, public, non-commercial APIs (Open-Meteo, LRCLIB).
